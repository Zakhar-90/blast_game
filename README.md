# Blast Puzzle Game

Прототип игры в жанре "головоломка с механикой Blast".

## Как играть

- Кликайте по группам из 2+ тайлов одного цвета
- Наберите 500 очков за 20 ходов
- Используйте бустеры (кнопки внизу)

## Бустеры

- **Телепорт** — поменять два тайла местами
- **Бомба** — уничтожить тайлы в радиусе 1 клетки

## Супер-тайлы

При удалении группы из 5+ тайлов появляется супер-тайл:
- Строка — уничтожает всю строку
- Столбец — уничтожает весь столбец
- Радиус — уничтожает тайлы в радиусе 2 клеток

## Технологии

- Cocos Creator 2.4.x
- TypeScript
